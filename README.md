# MemRoleVLA

**Memory-Grounded Skill and Role Inference for Long-Horizon Bimanual Manipulation**

## Abstract

In long-horizon bimanual manipulation, what to do next and which arm should execute it depend on which steps have already been completed, rather than only on the current observation window. Policies with short observation windows may advance before a step is complete or initiate recovery at an inappropriate moment. Existing atomic-skill methods do not explicitly exploit the history of online-confirmed completed events and therefore remain vulnerable to repetitive tasks and visual aliasing. We propose MemRoleVLA, a vision–language–action model that grounds step, skill, and role inference in confirmed event memory to guide atomic-skill action experts. A step-completion head estimates whether the active step has reached its goal; after continuous confirmation, the execution manager commits an evidence keyframe to memory through an idempotent single-write operation. The event memory is fused with the current observation to infer the next step, atomic skill, and execution role. The skill posterior routes shared action experts, while a role-conditioned action prior guides bimanual action generation. An event-value head, trained with successful demonstrations and outcome-labeled autonomous rollouts, estimates whether the current attempt can still succeed within its execution budget and supports bounded recovery together with observed goal-state changes. On real-world memory-dependent bimanual tasks, MemRoleVLA improves average success by 37.5 and 25.3 percentage points over π<sub>0.5</sub> and AtomicVLA*, respectively. Here * denotes our bimanual reproduction of AtomicVLA.
